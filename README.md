# 水下马赛克三角网核验台

补配马赛克之前，将散落碎片测点与人工连线整理成三角网，在浏览器里确认网格
**没有重叠、破口，或无法落在同一块平面上的局部结构**。全部判定只在本机进行，
页面不发起任何网络请求。

## 核验规则

按固定顺序给出**首个**不能作为连续拼补底图的风险证据（边按三角形录入过程中的
首次出现顺序编号 `e1…`，三角形按录入顺序编号 `T1…`）：

1. 测点 4–20 个，编号唯一、坐标为不重合的整数（坐标按 BigInt 精确解析与比较，
   允许超过 `Number.MAX_SAFE_INTEGER`（2^53-1）的任意大小整数，相邻超大整数
   不会因浮点舍入被误判重合）；
2. 每个三角形恰好引用 3 个存在且互不相同的测点编号，所有测点都须被引用；
3. 每个三角形**严格逆时针**（叉积为正，共线退化直接拒绝），全部使用 BigInt 精确比较；
4. 每条边恰被 1 或 2 个三角形使用，三面及以上拒绝；
5. 内部边必须两面相邻，且两面分列边的两侧（同侧折面/重叠拒绝）；
6. 顶点不得落在非关联边内部；不共端边交叉、相切、共线重叠一律拒绝；
7. 三角形内部不得相互重叠（顶点刺入另一三角形内部）；
8. 全部边界边必须沿唯一方向组成**一个简单闭环**：破口、分叉、顶点重复或多个
   分离环均拒绝。

## 目录

```
src/geometry.mjs   纯整数（BigInt）几何原语
src/verify.mjs     三角网核验主流程与首项证据
src/parse.mjs      测点 / 三角形文本解析
src/fixtures.mjs   有效网格与交叉网格示例
web/               原生 ESM 前端（录入、SVG、相邻面表、报告）
server.mjs         零依赖静态服务，含 /healthz
tools/build.mjs    前端构建（汇总到 dist/）
test/              node --test 单元测试与业务冒烟
```

## 本地运行（无需安装依赖，Node >= 20）

```bash
npm test           # 单元测试
npm run build      # 构建前端到 dist/
npm start          # 启动静态服务，默认 http://localhost:8080
npm run smoke      # 健康检查 + 有效/交叉两份网格的业务冒烟
npm run verify     # 测试 + 构建 + 冒烟，一键全量核验
```

## Docker

```bash
docker compose up web                 # 默认宿主机端口 8080
WEB_PORT=9000 docker compose up web   # 自定义宿主机端口
curl -s http://localhost:8080/healthz # {"status":"ok"}

docker compose run --rm verify        # 一次性服务：测试、构建、业务冒烟
```

`verify` 是一次性服务：成功以退出码 0 结束，任一失败以非零退出码报告。
容器内监听端口固定为 8080，宿主机端口由 `WEB_PORT` 配置；`web` 服务带
`/healthz` 健康检查（Dockerfile 与 compose 各声明一份）。

## 使用

- 测点每行：`编号 x y`；三角形每行：`a b c`（严格逆时针）；
  支持注释（`#`）与中文逗号/空白分隔。
- 点击“核验”后，SVG 标出三角形、内部边、边界环（绿色虚线）与风险位置，
  下方表格列出每条边的相邻面。
- 修改任意录入文本会立即**撤销旧报告**并灰化旧图，需重新点击“核验”。
